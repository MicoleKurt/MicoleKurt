## 🤖 Machine Learning — IRIS

> An AI road-condition and safety assessment system applying the international **iRAP Star Rating** methodology and **ASTM D6433** pavement standards. I built it independently after it was turned down as a thesis proposal, then pitched it to the Toll Regulatory Board — that presentation is what opened my consultancy there.

**I own the full ML lifecycle.** Dataset ingestion from public research corpora (CrackForest, RDD) → geometric and appearance augmentation → YOLOv8 fine-tuning → held-out evaluation → model comparison → decision-threshold tuning → bootstrap confidence intervals.

Training is engineered for **defensibility in a regulatory setting**:

```
  fixed seeds                  reproducible runs, end to end
  SHA-256 weight provenance    identify the exact base weights, not just the filename
  per-run training records     which images and label-review states produced this model
  no-network guarantee         enforced in code and in the test suite, not by policy
```

A finding derived from a model whose training data cannot be reconstructed cannot be defended when a regulator is challenged on it. That constraint shaped the whole pipeline.

**Six analysis modules** — pavement distress & PCI scoring · roadside severity classification · IRI roughness from phone accelerometer traces via a quarter-car model · nighttime lighting assessment · KDE crash-hotspot detection · random-forest risk fusion.

`~19,500 lines · 125 modules · 63 test suites` &nbsp;·&nbsp; Python · YOLOv8/Ultralytics · PyTorch · OpenCV · scikit-image · FastAPI · Flutter · Next.js

| **DBC AI Brain** | Cloudflare Workers · Supabase/pgvector · React · Anthropic & Vertex AI | Retrieval-augmented assistant platform for a US home-buying business. 14 versioned SQL migrations including a row-level-security policy layer and function-exposure hardening — **access control enforced in the database, not the prompt.** `~4,100 lines of SQL` |

One enforces authority **in code** — a change is refused unless it cites an approved backing field, with every refusal written to an audit log. ## 🧭 How I Work

**I write the specification before the agent runs.** I direct Claude Code as an orchestrated build system — written specs, custom subagents with explicit delegation boundaries, MCP server integration, project instruction sets encoding domain rules — while keeping architectural ownership and reviewing every diff.

**Deterministic pre-parsing before a model call**, so the model is only asked what it is actually needed for. A **re-prompt-once-then-fail-loud** pattern for malformed structured output, because a system that quietly accepts bad data is worse than one that stops.

**I remove AI where it cannot be defended.** On a regulated government system I replaced an LLM-driven evaluation layer with deterministic rules — "the model judged it this way" is not an answer an auditor accepts. AI stayed for ingestion, extraction, and drafting; nothing load-bearing for a decision.
